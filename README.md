# CoinGame (코인 수집 게임)
언리얼 엔진 5(Unreal Engine 5) C++로 개발된 3인칭 형태의 코인 수집 아케이드 게임입니다. 
제한된 시간 내에 맵 곳곳에 생성되는 코인을 획득하며 웨이브와 스테이지를 클리어하는 것이 목표입니다.

## 게임 특징 및 규칙
* **레벨 및 웨이브 시스템**: 
  * 총 3개의 레벨(스테이지)로 구성되어 있습니다.
  * 각 레벨은 다시 3번의 웨이브(Wave)로 나뉩니다.
  * 웨이브가 진행될수록 제한 시간이 짧아집니다 (1웨이브: 60초, 2웨이브: 40초, 3웨이브: 30초).
  * 맵에는 한 번의 웨이브 당 40개의 랜덤 아이템이 스폰 영역(`SpawnVolume`)을 통해 무작위로 생성됩니다.
 
* **목표**: 생성된 모든 코인(Coin)을 수집하면 현재 웨이브가 종료되며 다음 웨이브/레벨로 진행됩니다. 지정된 시간 내에 모두 모으지 못하면 웨이브가 종료됩니다.

## 캐릭터 조작 및 능력 (SpartaCharacter)
* **이동 (WASD)**: 기본 이동 속도로 움직입니다.
* **달리기 (Shift)**: 달리기 입력 시 이동 속도가 1.7배 증가하여 빠르게 이동합니다.
* **체력 시스템**: 최대 체력(`MaxHealth`)은 100이며, 체력이 0이 되면 게임 오버 화면과 메인 메뉴가 나타납니다.
* **카메라**: 스프링 암(`SpringArm`)을 이용해 캐릭터를 뒤따라가는 형태이며, 마우스로 시점을 조작할 수 있습니다.
  
## 아이템 종류 및 효과
* **작은 코인 (Small Coin Item)**
  * 획득 시 10점을 얻습니다.
  * 초당 90도의 속도로 자체 회전하는 연출이 있습니다.
* **큰 코인 (Big Coin Item)**
  * 획득 시 50점의 높은 점수를 얻습니다.
  * 작은 코인과 마찬가지로 제자리에서 회전합니다.
* **지뢰 (Mine Item)**
  * 획득 시 즉시 터지지 않고 5초의 지연 폭발 시간(`ExplosionDelay`)을 가집니다.
  * 폭발 시 300의 반경(`ExplosionRadius`) 내에 있는 플레이어에게 30의 데미지(`ExplosionDamage`)를 줍니다.
  * 폭발 효과 파티클과 사운드가 함께 재생됩니다.
* **회복 아이템 (Healing Item)**
  * 획득 시 플레이어의 체력을 20 회복시킵니다.
 
## 주요 클래스 구조
* **`SpartaCharacter`**: 캐릭터의 이동, 점프, 시점 이동(Enhanced Input 사용) 및 체력(HP)을 관리하며, 머리 위에 위젯을 띄워 현재 체력을 보여줍니다.
* **`SpartaGameState`**: 레벨/웨이브 진행, 스폰 조건 판단, 남은 시간 및 스코어 계산 등을 처리하는 게임의 두뇌 역할을 합니다. UI 타이머 업데이트 또한 관리합니다.
* **`SpawnVolume`**: 지정된 바운딩 박스 안에서 임의의 위치에 지정된 아이템 목록 중 하나를 스폰 시킵니다.
* **`SpartaGameInstance`**: 레벨을 넘나들어도 사라지지 않는 누적 점수와 현재 진행 중인 레벨 인덱스를 저장합니다.
* **`SpartaPlayerController`**: 사용자 입력 액션 매핑 및 게임 오버나 일시 정지 시 보여줄 UI/HUD 처리를 관장합니다.
